# Telegram Money Tracker Bot 💰

Мой первый Telegram-бот для учета личных финансов, написанный на Python.

## 🚀 Функционал:
*   `/add [сумма] [категория]` — добавить новую трату (например, `/add 500 Еда`).
*   `/total` — посмотреть общую сумму всех трат.
*   `/stats` — посмотреть статистику с разбивкой по категориям.
*   `/clear` — очистить историю трат.
*   Данные сохраняются в файл `expenses.json`, поэтому бот не забывает траты после перезапуска.

## 🛠 Технологии:
*   Python 3
*   pyTelegramBotAPI
*   JSON для хранения данных
*   Cloudflare Worker (для обхода блокировок)

## ⚙️ Как запустить:
1. Установите библиотеку: `pip install pyTelegramBotAPI`
2. Создайте файл `config.py` и положите туда ваш токен: `TOKEN = 'ваш_токен'`
3. Запустите файл `main.py`.
